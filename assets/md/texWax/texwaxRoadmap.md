## Phase 2 — Launch *(organic only)*
- [ ] Go public: anchors + first ~20-bar drop
- [ ] Post from the banked pipeline while producing new drops/reels
- [ ] Measure conversion per reel, not just reach; watch for the expectation gap in early reviews/DMs (the honesty rule exists to prevent it — verify it's working)
- [ ] First graduation decision when a drop earns it

## Phase 3 — Post-launch scaling *(gated)*
- [ ] Paid ads — **only after** bundle live + economics proven (contribution margin > CAC)
- [ ] Drop cadence steady; notify-list as the repeat-purchase engine
- [ ] Expand accessory subjects beyond boots (shoes, hats, bags content)
- [ ] Revisit consciously-deferred forks only if pulled: pre-waxed goods / kits / services; B2B inquiries (park politely, log them — they're future signal)
